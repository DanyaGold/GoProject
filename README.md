# Тестовое задание (Golang, PostgreSQL)

Сервис на Golang для параллельной загрузки данных о товарах и клиентах из внешних источников и сохранения в PostgreSQL.

## Стек технологий
* **Language:** Go 1.26.4
* **Database:** PostgreSQL
* **Orchestration:** Docker, Docker Compose

## Как запустить проект?

Для запуска выполнить команду в терминале:

```bash
docker-compose up --build
